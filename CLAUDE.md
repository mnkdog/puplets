# Puplets Project Configuration

## Plan Quality Standards

### Acceptance Criteria Guidelines
When writing acceptance criteria in implementation plans:
- **Be specific**: Use concrete values (hex codes, exact text, numeric thresholds) not vague terms like "should work" or "accurate"
- **Be testable**: Every criterion must have a verifiable pass/fail condition
- **Be complete**: Cover normal cases, edge cases, error conditions, and scope boundaries explicitly
- **Use examples**: "Cart modal heading uses #00AD50" beats "success message should be green"

This prevents delays at the spec-compliance-review gate.
